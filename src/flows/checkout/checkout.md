# Fluxo de Checkout

1. START: Apresenta o resumo do pedido e verifica se o cliente tem endereço
2. PAYMENT: Processa o método de pagamento selecionado
3. ADDRESS: Solicita o endereço se não estiver cadastrado
4. CHANGE: Pergunta se o cliente precisa de troco (quando pagamento em dinheiro)
5. OBSERVATIONS: Solicita observações para o pedido
6. FINISH: Finaliza o processo e permite iniciar um novo pedido
